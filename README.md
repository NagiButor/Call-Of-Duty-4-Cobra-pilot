# Call of Duty 4 — Cobra Pilot

Одиночная карта для Call of Duty 4 (PC) в духе вырезанной альфы IW «cobrapilot»: игрок сам
пилотирует ударный вертолёт **AH-1W SuperCobra** и командует танком **M1A1 Abrams**. Система
техники игрока сделана как заготовка для двух будущих миссий — пилот «Кобры» и экипаж «Абрамса».

## Возможности

**AH-1W SuperCobra**
- посадка по клавише использования, взлёт, посадка на шасси, выход на земле;
- три вида: кабина (модель `cobra_interior_viewmodel`), камера сзади и камера стрелка
  (тепловизор NTS FLIR, WHOT/BHOT, широкое/узкое поле зрения);
- вооружение: пушка M197 20 мм, НУРСы LAU-61C/A, AGM-114 Hellfire (по наземным целям, с
  захватом), AIM-9 Sidewinder (по воздушным), тепловые ловушки;
- ИИ-стрелок в передней кабине ведёт огонь из 20 мм, пока пилот стреляет ракетами;
- полётная модель на системе целей ИИ-вертолётов движка: торможение у стен и скайбокса,
  обход рельефа, плавная посадка;
- HUD в стиле альфы: скорость, высота, список оружия, ловушки, силуэт повреждений,
  предупреждения о ракетах и земле, точки перевооружения (FARP), границы района.

**M1A1 Abrams**
- вождение движком, башня следует за взглядом, камера сзади и прицел наводчика с зумом;
- перекрестие стационарного MG42, перезарядка 120 мм с индикатором снаряда;
- спаренный пулемёт на правой кнопке мыши, бронирование корпуса.

Урон от оружия техники засчитывается игроку (дружественный огонь проваливает миссию, как
в стоковых уровнях). Управление следует за переназначенными клавишами игрока.

## Состав репозитория

Репозиторий повторяет структуру папки игры:

| Путь | Что это |
|---|---|
| `map_source/cobra_pilot.map` | исходник карты (Radiant) |
| `raw/maps/cobra_pilot.gsc` | скрипт уровня |
| `raw/maps/cobra_pilot.d3dbsp` | скомпилированная карта (свет, пути ИИ, отражения) |
| `raw/maps/_playervehicle*.gsc` | система техники игрока |
| `raw/maps/_playervehicle_README_ru.txt` | подробная справка: подключение к миссиям, ключи Radiant, API, настройки |
| `raw/vehicles/` | `cobra_pv` и стоковые описания техники (нужны `sp_tool` для путей и отражений) |
| `raw/weapons/sp/*_pv` | оружие техники игрока |
| `raw/sound/cobra/`, `raw/soundaliases/playervehicle.csv` | звуки |
| `raw/english/localizedstrings/` | строки уровня и системы |
| `zone_source/cobra_pilot.csv` | состав fast file |
| `zone/english/cobra_pilot.ff` | готовая сборка уровня |

## Установка и запуск

1. Скопируйте содержимое репозитория в папку Call of Duty 4 (с объединением папок).
2. Запустите игру, откройте консоль и введите `devmap cobra_pilot`.

## Сборка

Нужны CoD4 Mod Tools.

- Перед первой сборкой HUD перезарядки выполните из папки игры:
  `powershell -ExecutionPolicy Bypass -File tools\build_reload_hud.ps1`.
  Нужен CoD4-совместимый HLSL `shader_tool.exe` в `raw/shader_bin` (обычный linker
  сам HLSL не компилирует). Подготовка Shader Tool:
  [инструкция](https://github.com/Zoro-6191/cod4-2d-shaders/wiki/How-to-Install-1-shader).
  Скрипт собирает шейдер и создаёт `pv_reload` из штатного `raw/materials/tank_shell`:
  используется исходная текстура без новых картинок. Техсет `pf` имеет короткое имя,
  чтобы безопасно сохранить смещения строк в бинарном материале.
- Fast file: из папки `bin` выполнить `linker_pc.exe -language english cobra_pilot`.
- Карта: BSP + Light (IW3xRadiant или CoD4 Compile Tools) → Paths → Reflections → Build Fastfile.
  - Объём браша `lightgrid_volume` должен давать не больше 1 048 576 точек сетки (шаг 32 × 32 × 64),
    иначе `cod4rad` прерывается и карта остаётся без света.
  - Paths и Reflections запускают `sp_tool` с `useFastFile 0`: описания всей техники с карты должны
    лежать в `raw/vehicles`.

## Управление

| | «Кобра» | «Абрамс» |
|---|---|---|
| Движение | W/S вперёд/назад, A/D вбок, Пробел/Shift вверх/вниз | W/S ход, A/D поворот корпуса |
| Мышь | обзор, нос следует за взглядом | башня |
| ЛКМ | огонь | пушка 120 мм |
| ПКМ | зум | спаренный пулемёт |
| Прочее | 1/2 смена оружия, G ловушки, V вид, R полярность FLIR | Shift зум, V вид |
| F | сесть / выйти на земле | сесть / выйти на остановке |
